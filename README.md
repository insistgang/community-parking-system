# 慧停管家 · 老旧小区停车位管理系统

面向老旧小区车位供需失衡治理的**公平排位、三证合一准入、虚拟区块链存证**全栈演示系统。基于产品需求规格说明书 PRD-V3.0 落地，纯离线自包含、零外部 CDN 依赖，专为 **2026-09-09 向张总汇报评审** 打造。

---

## ✨ 核心特性

### 业主移动端 (H5)
- **双通道登录**：账号密码 + 短信验证码（演示码 `888888`），登录页内置四大演示账号一键填充
- **三证合一申请**：身份证/结婚证 OCR 拟真扫描（1 秒雷达光带动效），仅提取证号与姓名，服务端不持久化任何证件图片
- **外区房强制拦截**：名下外区房产（如浦东新区世纪大道）置灰不可选，前端阻断 Toast + 后端二次强校验
- **夫妻车智能引导**：行驶证所有人与房产所有人姓名不一致时，自动弹窗引导上传结婚证
- **动态 4 重视图**：`NO_APPLY`（未申请）/ `WAITING`（排队中）/ `ALLOCATED`（中签 48h 金色倒计时）/ `RENTED`（在租含临期催缴进度条）
- **阳光公示**：全队列脱敏公示（张\*\*、138\*\*\*\*0001）、个人排位轨迹时间线、AI 预估等待时长
- **区块链存证中心**：66 位 SHA-256 交易哈希一键复制、区块高度、防伪验真证书弹窗，全局统一底部导航栏随时切换

### 物业管理中台 (PC 宽屏 & 巡检模式)
- 50 车位资产大屏看板与台账矩阵（地面/地下、已租/空闲/待办/维修状态一览）
- **任意车位直接维修停用与验收恢复**：支持选择空闲、已分配或在租的任意车位，直接置为维修停用并登记故障原因与存证上链；验收合格后一键“验收恢复上线”，自动触发调度引擎重排分配
- **物业前后台双视角巡检**：物业管理员（王建国）可随时点击左上角“返回业主端”进入移动端巡检视角，顶部常驻巡检横幅与一键返回中台入口，彻底解决角色混淆与串号问题
- **严格杜绝插队与角色隔离**：管理后台坚决不提供任何“手动指派”车位的接口或按钮；同时后端与前端多层严格阻断物业管理员账号申请车位排队，车位只能由 FIFO 调度引擎自动分发
- 线下签约交付确认（仅允许系统已分配的中签车位办理，生成 1 年期正式租约并区块链存证）
- 强制代清退（上传凭据、填写原因），释放车位秒级顺延

### 调度引擎与存证
- **FIFO 原子重排**：一车优先于二车（`priority_level`）、同优先级按申请时间戳排序
- **48h 严格倒计时**：中签后精确到秒确认期，超时自动判定放弃出列并顺延（后台每分钟定时清扫 + 主页访问惰性触发，双层保障）
- **顺位秒级联动**：物业端清退/车位释放 → 业主端 3 秒轮询内排位自动前移并推送通知
- **虚拟区块链**：哈希链式结构（`tx_hash` / `prev_hash`）、自增区块高度、业务快照全文上链、防伪证书验真

## 🐳 Docker 生产与服务器部署

系统已提供企业级 Docker 化支持，支持 **Docker Compose 多容器微服务架构** 与 **单容器一体化极速部署**，内置 Nginx 高性能反向代理、静态资源 Gzip 压缩与 SQLite 宿主机数据持久化。

### 方式一：一键自动化部署（最省心推荐）
在服务器拉取代码后，执行一键部署脚本即可（自动检测 Docker / Compose 环境并智能拉起）：
```bash
bash docker-deploy.sh
```

### 方式二：Docker Compose 标准编排
```bash
# 1. 复制环境变量（默认对外暴露 80 端口，可按需修改）
cp .env.example .env

# 2. 构建镜像并后台拉起
docker compose up -d --build

# 3. 运维常用命令
docker compose ps               # 查看容器状态
docker compose logs -f          # 查看实时运行日志
docker compose down             # 停止并移除容器
```

### 方式三：单容器一体化运行（无需 Compose）
```bash
# 1. 构建一体化单镜像（同时打包 Vue 3 + FastAPI + Nginx）
docker build -t community-parking .

# 2. 创建持久化数据目录并启动容器
mkdir -p data
docker run -d \
  --name parking-app \
  --restart always \
  -p 80:80 \
  -p 8000:8000 \
  -v $(pwd)/data:/app/data \
  community-parking
```

### 部署网络与存储说明
- **统一访问入口**：直接访问 `http://<服务器IP>/` 即可进入移动端，PC 打开自动适配宽屏
- **物业管理中台**：`http://<服务器IP>/property/dashboard`
- **Swagger 接口文档**：`http://<服务器IP>/docs`
- **数据持久化**：所有车位资产、排位与存证数据持久化保存在宿主机 `./data/parking.db`，容器重新构建或重启升级数据 100% 不丢失。

## 🔌 主要 API 一览

统一响应结构：`{"code": 200, "message": "success", "data": ...}`；鉴权方式：请求头 `X-User-Id`。

| 模块 | 端点 | 说明 |
|---|---|---|
| 认证 | `POST /api/auth/login` · `POST /api/auth/send-sms` · `POST /api/register` · `GET /api/common/districts` | 账号/短信双通道登录、行政区划 |
| 业主 | `GET /api/user/home` · `POST /api/parking/apply` · `POST /api/parking/cancel-apply` · `POST /api/parking/accept-allocation` · `POST /api/parking/give-up-allocation` · `POST /api/parking/terminate-rental` · `POST /api/parking/renew` · `GET /api/parking/queue` · `GET /api/parking/my-timeline` · `GET /api/notifications` | 四重动态视图、申请、撤销、排位、时间线 |
| 物业 | `GET /api/property/stats` · `GET /api/property/spaces` · `GET /api/property/export-spaces` · `POST /api/property/set-maintenance` · `POST /api/property/confirm-delivery` · `POST /api/property/force-terminate` · `POST /api/property/init-demo-spaces` | 大屏数据、任意车位维修停用与验收恢复、交付、清退 |
| 存证 | `GET /api/evidence/list` · `GET /api/evidence/verify/{evidence_id}` | 存证流水列表、防伪证书验真 |
| 开发 | `POST /api/dev/reset-seed` | 一键秒级重置 50 车位与 4 演示账号 |

## ⚠️ 架构与合规说明

- 本系统为**汇报评审演示系统**：鉴权采用轻量化 `X-User-Id` 机制，区块链为单节点虚拟哈希链式存证实现
- 所有时间戳统一采用 UTC 存储，48h 倒计时由服务端计算剩余秒数、前端高精度动态倒计时驱动
- 详细技术与业务规范见 [agents.md](agents.md)，详细演示解说分镜见 [DEMO_GUIDE.md](DEMO_GUIDE.md)
